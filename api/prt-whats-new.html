PRT // DEVELOPMENT LOG

WHAT'S NEW.

PRT is built in real race nights with real testers. This is the running record of what shipped, what improved, what broke, and what we're still working on.

EARLY ACCESSSEPTEMBER 2026

NEW

Race-night tools continue to expand

Live overlays, Relative, Standings, Track Map, proximity awareness and race context are being tested together as one race-night environment.

Race Intelligence foundation

Work continues toward persistent race memory, Driver DNA, Race Autopsy and a smarter Spotter / Coach experience.

Broadcast Studio foundation

The first broadcast workflows are in Early Access. This area is intentionally still barebones while the core driver experience is hardened.

IMPROVED

Radar stability

Recent testing and hotfix work improved radar behavior and stability during live sessions.

Real-session development loop

League and multi-driver testing is now feeding bugs, friction and feature requests directly into active builds.

FIXED / UNDER ACTIVE TEST

Updater reliability

Recent release-candidate work is being verified across multiple tester machines and update paths.

Session-aware spotter behavior

Filtering and state-transition work is targeting false calls and repetitive chatter, especially in qualifying and low-traffic sessions.

KNOWN ISSUES

Track Map first-lap behavior

The map may remain incomplete until enough track position data has been collected in-session.

Relative layout and race context

Spacing, nearby-car depth and clearer lap-ahead / lap-behind context remain active development items.

Display scaling

Large-display and high-scaling setups can expose text readability issues that are still being tuned.

Metric fuel calls

Some voice output may still use imperial fuel units when the driver expects metric.
