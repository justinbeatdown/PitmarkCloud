WHAT WE NEED FROM TESTERS

Useful feedback beats hype.

You do not need to make content or praise PRT. We need racers willing to use it, break it, question it, and tell us what actually belongs on race night.

  • Windows PC + iRacing
  • 1–2 real testing sessions when feedback is needed
  • Useful bug reports: car/track, expected vs. actual, screenshot when possible
  • Honest feedback, including when you dislike a feature or design choice
