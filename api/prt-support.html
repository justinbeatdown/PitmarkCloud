What do you need help with?

Start with the quick answers below. If that doesn't solve it, Pitmark Support is ready to help.

How do I install Pitmark Racing Tools?

Download the current Windows build when your account has access, run the installer, then launch PRT before or alongside iRacing.

Why does PRT say “Waiting for iRacing”?

That is the normal idle state. Launch iRacing and enter a session; PRT will begin receiving live telemetry when the simulator exposes session data.

How do I use the on-screen overlays?

Open Overlays inside PRT, enable the displays you want, and configure their layout for your race session.

How do I add the Pitmark Bot to Discord?

Use the Add Pitmark Bot button on the PRT site, choose a Discord server where you have permission to install apps, and approve the requested permissions.

How does Early Access and licensing work?

Early Access accounts receive the features enabled for their current Pitmark entitlement. Additional features and tiers will be introduced as PRT develops.

I found a bug or something isn't working. What should I do?

Check the known/common issues here first. If the problem remains, use Report a Problem below and include what you were doing, what happened, and your PRT version.
