01How do I install and start Pitmark Racing Tools?
  1. Apply for Early Access if you do not already have an activation code.
  2. Download the current Windows installer and run it on the PC you use for iRacing.
  3. Launch PRT and enter your Early Access activation code.
  4. Launch iRacing and enter a session, then enable the PRT overlays you want to use.
02PRT is locked or my activation code is not working. What now?

The installer is public, but Early Access requires a valid activation code. If you have not received one, apply here. If your code is rejected or you changed PCs, contact PRT Support with the exact error and your PRT version. Keep your activation code private.

03Can I run PRT on my phone or Mac?

The current PRT app is built for Windows on the PC running iRacing. You can use the website, Early Access application, Discord, and support from your phone, then install PRT on your racing PC.

04Why does PRT say “Waiting for iRacing”?

That is the normal idle state when the simulator is not exposing live session data. Launch iRacing and enter a session. If PRT still waits while you are on track, send support your PRT version, car, track, session type, and a screenshot of the PRT status.

05How do I use or troubleshoot the on-screen overlays?

Open Overlays inside PRT, enable the displays you want, and configure the layout for your session. If data or placement looks wrong, include a screenshot showing both the PRT overlay and the corresponding iRacing information. For radar, standings, lap count, inputs, or track-map problems, tell us exactly which overlay is affected.

06How do I use PRT with Discord?

Use Add Pitmark Bot if you manage a server, or join the Pitmark Discord for releases, tester discussion, support, and feedback.

07How does Early Access and licensing work?

Early Access currently requires a Pitmark-issued activation code. The PRT app reads the entitlement tied to that activation. If you were accepted but access does not match what you were given, contact support with your PRT version and the error you see.

08I found a bug. What should I send?

Include your PRT version, car and track, session type, what you expected, what happened, and the steps that reproduce it. A screenshot or short clip is extremely helpful. If the problem involves standings, lap count, radar, inputs, or the track map, include the matching iRacing display when possible.
