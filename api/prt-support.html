What do you need help with?

New to PRT? Start with Early Access, install the Windows app, then connect to iRacing.

APPLY FOR EARLY ACCESS DOWNLOAD PRT — WINDOWS

A valid Early Access activation code is required to enter PRT. Downloading the installer does not grant access. The application opens in Google Forms and requires Google sign-in. Need help applying? Email PRT Support.

How do I install and start Pitmark Racing Tools?
  1. Apply for Early Access if you do not already have an activation code.
  2. Download the current Windows installer and run it on the PC you use for iRacing.
  3. Launch PRT and enter your Early Access activation code. Early Access includes activation on one device.
  4. Launch iRacing and enter a session, then enable the PRT overlays you want to use.
PRT is locked or my activation code is not working. What now?

The installer is public, but Early Access requires a valid activation code. If you have not received one, apply here. If your code is rejected or you have changed PCs, contact PRT Support with the exact error and your PRT version. Keep your activation code private.

Can I run PRT on my phone or Mac?

The current PRT app is a Windows download for the PC running iRacing. You can browse the website and apply from your phone, then open the download link on your racing PC.

Why does PRT say “Waiting for iRacing”?

That is the normal idle state. Launch iRacing and enter a session; PRT will begin receiving live telemetry when the simulator exposes session data. If it remains waiting while you are in a session, tell support your PRT version, the car and track, and whether the session is Test Drive, Practice, Qualifying, or Race.

How do I use the on-screen overlays?

Open Overlays inside PRT, enable the displays you want, and configure their layout for your race session. For a layout or data problem, include a screenshot showing the overlay and the corresponding iRacing information.

How do I add the Pitmark Bot to Discord?

Use Add Pitmark Bot, choose a Discord server where you have permission to install apps, and review the requested permissions. For PRT updates and community support, join the Pitmark Discord.

How do PRT plans and licensing work?

PRT has Free, Pro, and League / Team tiers. Your Windows app receives the features enabled by your current entitlement. During Early Access, a valid activation code is required to enter the app. Review the plans and current Early Access information, or contact support if your purchased plan and app access do not match.

I found a bug or something isn't working. What should I include?

Use Report a Problem below and include your PRT version, car and track, session type (Test Drive, Practice, Qualifying, or Race), what you expected, what happened, and the steps that reproduce it. Attach a screenshot or short clip when possible. For standings, lap-count, or track-map issues, show the matching iRacing display too.
