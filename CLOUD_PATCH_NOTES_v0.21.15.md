# Pitmark Cloud v0.21.15

Cloud-only release. PRT Windows binaries and updater manifest are not included or modified.

## Included
- Pitmark branded links hub at `/links`
- Host routing for `links.pitmarkracing.com`
- Shop, PRT, PRT Early Access, and Contact destinations
- Cloud version bump to `0.21.15`

## Preserved
- Autopilot intelligence scheduler
- Multiplatform scheduler
- Research worker
- Social publishing worker
- Shield / Gmail protection
- Discord integrations
- Control Center access controls and security middleware

## Deployment
Copy the contents of this ZIP into the root of the existing PitmarkCloud repository,
preserving folders, then commit/push the changed Cloud files. Do not replace or modify
PRT installer/update-manifest files.
