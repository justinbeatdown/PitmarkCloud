# Pitmark Cloud v0.16.19 — Shield-Aware Mail UI

Makes Pitmark Mail the primary place to judge email safety.

Desktop:
- Shield verdict and confidence shown directly on each inbox message.
- Expanded message view shows classification, confidence, reasons and Shield action.
- Shield status is surfaced beside normal mail status.
- Inbox uses the full workspace until a conversation is selected, then switches to a clean split view.
- Mail cards, toolbar and conversation pane receive a tighter Control Center visual treatment.

Mobile:
- Same Shield verdict/confidence badges in the inbox.
- Same detailed Shield assessment inside opened messages.
- Same Shield-active status.

No mail-routing, Resend, DNS, sender-identity, deletion, or Shield classification logic is changed.
